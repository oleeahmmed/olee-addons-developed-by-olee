# POS অ্যাডঅন — বাংলাদেশের যেকোনো দোকানের জন্য (Odoo 19)

এই `pos` ফোল্ডারে POS-এর সব অ্যাডঅন। একটা **কোর** (`pos_modern`) সব দোকানে লাগে, বাকিগুলো
দোকানের ধরন অনুযায়ী ইনস্টল করুন। কোনো অ্যাডঅনে আলাদা CSS নেই — সব স্টাইল
`modern_theme/static/src/scss/apps/` এ (pos.scss, pos.dark.scss, pos_report.scss, pos_frontend.scss)।

| অ্যাডঅন | কার জন্য | কী দেয় |
|---|---|---|
| `pos_modern` | সব দোকান (কোর) | কাউন্টার: স্প্লিট পেমেন্ট, চেঞ্জ, কুইক ক্যাশ নোট, হোল্ড বিল, লাইন/বিল ডিসকাউন্ট + ম্যানেজার PIN, নোট, ৫৮/৮০মিমি রিসিট প্রিন্ট, শর্টকাট (F2–F10), স্টক দেখা, মোবাইল নম্বরে কাস্টমার খোঁজা ও তৈরি, অফলাইন কিউ, ডে-এন্ড (X/Z রিপোর্ট, ক্যাশ ইন/আউট, ক্যাশ গুনে সেশন ক্লোজ), কাউন্টার সেটিংস, **রিটার্ন/এক্সচেঞ্জ** (রসিদ নম্বর স্ক্যান করে ফেরত, পার্থক্য নেওয়া/ফেরত), **বারকোড লেবেল** (৩৮×২৫/৫০×৩০/৫৮×৪০, নিজস্ব EAN-13 তৈরি), **মডিফায়ার** (ঝাল কম, এক্সট্রা চিজ +৪০…), কেজি/লিটার পণ্যে পরিমাণের প্যাড |
| `pos_bd_payment` | BD-র প্রায় সব দোকান | bKash/Nagad/Rocket/Upay আলাদা টেন্ডার (এক ক্লিকে সেটআপ), TrxID + পেয়ার নম্বর, ডুপ্লিকেট TrxID আটকানো, ওয়ালেট রিকনসিলিয়েশন পেজ (স্টেটমেন্ট পেস্ট করলে মিলে যায়), SMS রিসিট (BulkSMSBD / SSL Wireless / কাস্টম) |
| `l10n_bd_pos` | VAT নিবন্ধিত দোকান | BIN (কোম্পানি ও কাস্টমার), মূসক-৬.৩ কর চালানপত্র ও মূসক-৬.৭ ক্রেডিট নোট (A4 PDF, নিজস্ব নম্বর), VAT/SD/AT আলাদা, VAT সেলস রেজিস্টার, বাংলা নাম ও বাংলা অঙ্কে রিসিট, কথায় টাকা |
| `pos_pharmacy` | ফার্মেসি | জেনেরিক নামে খোঁজা, পিস/স্ট্রিপ/বক্স, ব্যাচ FEFO (আগে মেয়াদ শেষ হবে সেটা আগে), মেয়াদোত্তীর্ণ ব্লক, প্রেসক্রিপশন (ডাক্তার/রোগী), নিয়ার-এক্সপায়ারি পেজ |
| `pos_restaurant_bd` | রেস্টুরেন্ট/ক্যাফে | ডাইন-ইন/টেকঅ্যাওয়ে/ডেলিভারি, KOT (শুধু নতুন আইটেম), কিচেন স্ক্রিন, টেবিলে খোলা বিল, সার্ভিস চার্জ, Foodpanda/Pathao রেফ, ডেলিভারি চার্জ, QR মেনু + টেবিল QR কার্ড, ফ্লোর প্ল্যান (টেবিলের অবস্থা, সময়, ওয়েটার), স্টেশন অনুযায়ী আলাদা KOT, ওয়েটার/রাইডার, গেস্ট চেক (বিল চাওয়া), টেবিল সরানো/বিল এক করা, কমপ্লিমেন্টারি, মাথাপিছু বিক্রি |
| `pos_retail_bd` | মুদি/সুপারশপ/পোশাক | অফার (% ছাড়, Buy X Get Y, বিলে টাকা ছাড়), লয়ালটি পয়েন্ট, বাকি (লিমিটসহ) ও বাকি আদায়, কাস্টমারের আগের কেনা, ওজন-স্কেল বারকোড, প্যাক/কার্টন বিক্রি, কুইক কি (বারকোড ছাড়া পণ্য), IMEI/সিরিয়াল, গোডাউন স্টক দেখা, স্টক গণনা ও নষ্ট বাদ |
| `pos_clothes` | কাপড়/জুতা/ফ্যাশন | প্রতি স্টাইলে এক কার্ড, সাইজ × রঙের ম্যাট্রিক্স, কাপড়/সিজন/যত্নের লেখা, হ্যান্ড ট্যাগ লেবেল, সাইজ রিপোর্ট (কোনটা চলে, কোনটা শেষ, কোনটা পড়ে থাকে) |
| `pos_bakery` | বেকারি/মিষ্টির দোকান | কিউ টোকেন (আলাদা স্লিপ), সকালের বেক (রেসিপি থাকলে উপকরণ খরচ), নষ্ট বাদ, কাস্টম কেকের অর্ডার + অগ্রিম + ডেলিভারি, বেকারির দিনের রিপোর্ট। `mrp` লাগে |

## কোন দোকানে কী ইনস্টল করবেন

* মুদি / সুপারশপ / মোবাইল-ইলেকট্রনিক্স: `pos_modern` + `pos_bd_payment` + `pos_retail_bd` (+ `l10n_bd_pos`)
* কাপড়ের দোকান: উপরের সাথে + `pos_clothes`
* বেকারি / মিষ্টি: `pos_modern` + `pos_bd_payment` + `pos_bakery` (+ `pos_retail_bd`)
* ফার্মেসি: `pos_modern` + `pos_bd_payment` + `pos_pharmacy` (+ `l10n_bd_pos`)
* রেস্টুরেন্ট: `pos_modern` + `pos_bd_payment` + `pos_restaurant_bd` (+ `l10n_bd_pos`)

এক ডাটাবেসে কয়েক ধরনের দোকান থাকলে সব ইনস্টল করুন: প্রতিটা শপের **Counter settings**
(কাউন্টারের ⚙ বাটন) এ "Pharmacy counter", "Restaurant counter" ইত্যাদি চালু/বন্ধ করা যায়।

## ইনস্টল / আপগ্রেড

```bash
# odoo.conf-এ addons_path: ...odoo/addons, ...custom-addons/pos, ...custom-addons
python odoo-bin -c odoo.conf -d odoo_fresh -u modern_theme,pos_modern
python odoo-bin -c odoo.conf -d odoo_fresh -u modern_theme,pos_modern,pos_bd_payment,pos_pharmacy,pos_restaurant_bd,pos_retail_bd
python odoo-bin -c odoo.conf -d odoo_fresh -i pos_clothes,pos_bakery
```

তারপর ব্রাউজারে Ctrl+Shift+R।

## সহজ ফর্ম (ড্রয়ার)

Configuration ও More মেনুর সহজ রেকর্ডগুলো (পেমেন্ট পদ্ধতি, প্রিসেট, কয়েন/নোট, ফ্লোর, নোট মডেল,
মডিফায়ার, অফার, ওয়েটার/রাইডার, ওষুধ, স্টাইল, কেকের অর্ডার…) Odoo-র ফর্মের বদলে CRM-এর মতো ডান পাশের
ড্রয়ারে খোলে। SMS গেটওয়ে ও VAT রেজিস্ট্রেশন একটি সহজ পেজে। ড্রয়ারটা `modern_theme`-এর
(`static/src/js/app_kit/smart_drawer.js`), তাই অন্য অ্যাপের কনফিগারেশন (ট্যাগ, গুদাম, লোকেশন, ছুটির ধরন,
ওয়ার্ক সেন্টার…) একই ড্রয়ারে খোলে। লাইনযুক্ত রেকর্ড (প্রাইসলিস্ট, কর, পেমেন্ট টার্ম…) ও দোকানের সেটিংস
Odoo-র পূর্ণ ফর্মেই থাকে; ড্রয়ারের "Open full form" দিয়েও সেখানে যাওয়া যায়।

নতুন মডেল যোগ করতে অ্যাডঅনের `static/src/js/drawer_forms.js`-এ:

```js
import { drawerForms } from "@modern_theme/js/app_kit/smart_drawer";
drawerForms.add("my.model", { title: _t("…"), newTitle: _t("New …"), fields: ["name", ["a", "b"], { name: "color", widget: "color" }] });
```

## শপ অ্যাডঅন বানানোর নিয়ম

* `depends`: `['pos_modern', ...]`। নতুন CSS ফাইল নয় — `ps-*` ক্লাস ব্যবহার করুন; নতুন স্টাইল লাগলে
  `modern_theme/static/src/scss/apps/pos.scss`-এ যোগ করুন।
* সার্ভার হুক (`pos.config`): `_pos_modern_features`, `_pos_modern_extend_rows`,
  `_pos_modern_adjust_lines`, `_pos_modern_allowed_methods`, `_pos_modern_method_row`,
  `_pos_modern_check_payments`, `_pos_modern_payment_vals`, `_pos_modern_order_vals`,
  `_pos_modern_after_order`; রিসিট: `pos.order._pos_modern_receipt_data`; X/Z:
  `pos.session._pos_modern_session_report_extra`।
* স্ক্রিন: `patch(PosMenu.prototype, …)` আর `pos_modern.Menu` / `pos_modern.Receipt`-এর
  `.ps-hook-*` / `.ps-r-hook-*` জায়গায় `t-inherit`।
* সেটিংস: `pos_modern.pos_config_counter_form`-এর `<div name="pm_addons">`-এ inherit।

## জেনে রাখুন

* রিসিট ব্রাউজার থেকে প্রিন্ট হয়: থার্মাল প্রিন্টারকে ডিফল্ট প্রিন্টার করুন, ডায়ালগ ছাড়া
  প্রিন্টের জন্য Chrome `--kiosk-printing`। ক্যাশ ড্রয়ার কিক ও সরাসরি ESC/POS-এর জন্য Odoo IoT/ePOS প্রিন্টার লাগে।
* অফলাইন: কাউন্টার খোলা অবস্থায় নেট/সার্ভার গেলে বিল ব্রাউজারে জমা থাকে, ফিরলে নিজে পাঠায়।
  Odoo সার্ভার দোকানের পিসিতেই (127.0.0.1) থাকলে ইন্টারনেট না থাকলেও বিক্রি চলে।
* SMS গেটওয়ের API আপনার প্রোভাইডারের ডকুমেন্টের সাথে মিলিয়ে নিন। মূসক ফর্ম NBR বদলালে VAT পরামর্শকের সাথে মিলিয়ে নিন।
* বাকির হিসাব: সেশন খোলা থাকা অবস্থার বাকিও ধরা হয়; বাকি আদায় "Collect dues in" জার্নালে পোস্ট হয় (ক্যাশ ড্রয়ারের গোনার বাইরে)।
